Clásica moderna

↗ Probar Aurora a pantalla completa

Una estructura familiar, pulida y fácil de usar.

Ver prompt completo ↓

Barra horizontal limpia con logo AURORA, enlaces Inicio, Servicios, Proyectos, Contacto y CTA Comenzar. Fondo marfil, bordes redondeados, tipografía sans serif negra. Diseña un componente responsive con menú hamburguesa accesible en móvil, hover, focus visible y HTML CSS JavaScript completos.

Contraste fuerte entre tres zonas independientes.
