# Aptitud Labs — Versión inicial motion

Versión independiente de la web creada en esta conversación, con bienvenida animada y diseño adaptable. El HTML incluye CSS y JavaScript; no requiere dependencias ni compilación.

La web principal del repositorio permanece en la raíz. Esta carpeta conserva la primera propuesta sin reemplazar los avances posteriores.

Para publicar esta versión en Vercel, utiliza `version-inicial-motion` como Root Directory y el preset Other, sin comando de compilación.

El formulario de esta versión prepara texto para copiar; no envía solicitudes ni incluye un número de WhatsApp configurado.
