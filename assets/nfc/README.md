# Imágenes NFC

Los 15 archivos `.webp` de esta carpeta están preparados en el paquete `aptitud_nfc_15_imagenes_web.zip` entregado al propietario.

Sube los archivos conservando exactamente sus nombres a `assets/nfc/` mediante GitHub (Add file > Upload files). El catálogo usa `google.webp`, `whatsapp.webp`, `instagram.webp`, `business.webp`, `keychain.webp` y `stand.webp`. Mientras no estén subidos, muestra un fondo de reserva y no imágenes inventadas.

La página utiliza imágenes generadas como mockups ilustrativos; confirmar los materiales y acabados reales antes de vender.
