# Dirección fotográfica V7 — Aptitud Labs Preview

El código del preview ya está preparado para tres imágenes WebP generadas para la web:

- `assets/visuals/servicios-realista.webp` — escritorio con laptop, tablet y celular.
- `assets/visuals/planes-realista.webp` — propuesta, documentos, tablero y planificación.
- `assets/visuals/nfc-realista.webp` — soporte de mesa NFC, tarjetas, QR y teléfono.

Las tres imágenes se proporcionan en el archivo **aptitud-labs-fotografia-v7.zip** del chat.

**Carga desde Android:**
1. Descomprime el ZIP.
2. Abre la carpeta `assets/visuals` de la rama **preview/github-pages-motion-v5**.
3. Usa **Add file → Upload files** y selecciona los tres archivos WebP.
4. Confirma el commit **directamente en esta rama de vista previa**, no en `main`.
5. El workflow actualiza automáticamente la rama `gh-pages`.

Las páginas detectan si las fotos están presentes y solo las muestran una vez cargadas; antes de subirlas siguen usando las imágenes de demos existentes sin dejar huecos o iconos de error.

Estas fotografías son **conceptos generados con IA**, no fotografías de clientes ni productos fabricados. No son sustitutos de un catálogo fotográfico de inventario real. El QR de la composición de muestra no se debe presentar como un QR funcional.
