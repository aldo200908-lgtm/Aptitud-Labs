# Aptitud Labs — Motion Graphics

Proyecto Remotion de 30 segundos, 1080×1920, 30 fps.

**Importante:** antes de ejecutar, coloca el logotipo original en `public/logo.png` (pendiente de subir a GitHub).

En Codespaces, desde esta carpeta:

```bash
npm install
npm run start
```

Para exportar:

```bash
npm run render
```

Salida: `out/aptitud-labs.mp4`. El proyecto no incluye audio.
